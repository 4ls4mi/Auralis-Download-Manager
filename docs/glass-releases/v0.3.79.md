## Browser integration

- Auralis checks Chrome and Edge profiles for current extension registration. Once the browser reports removal, an earlier connection no longer keeps the extension marked as installed.
- **Reset extension setup** rechecks the browser and can clear the automatic setup Auralis created. If the browser still has the extension, Auralis opens its Extensions page so you can confirm removal there.
- Automatic setup shows when an install request was saved and when Windows denied the request. Chrome or Edge applies the request and installs the extension when its settings allow it.
