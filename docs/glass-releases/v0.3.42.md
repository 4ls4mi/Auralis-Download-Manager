## Browser video panel

- Choose a subtitle language above the video quality list. Separate subtitle files and selectable embedded tracks are available; embedding requires FFmpeg and a supported video container.
- Quality choices use compact two-line entries with available duration, size, resolution and codec information.
- Permanent subtitle burn-in is not yet available and is shown as unavailable; embedding is a selectable track, not burn-in.

The browser extension packages are version 0.1.12. Browser store updates require a separate store submission.
