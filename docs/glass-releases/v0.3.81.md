## Browser integration

- Automatic setup verifies the saved installation request before asking Chrome 142 or later to reload. When a request already exists, **Finish setup** reuses it. Chrome installs the extension from the store when it applies the request.
- Browser integration explains how to remove an automatically installed extension. Choose **Reset extension setup** first to clear the setting Auralis created, then remove the extension from the browser if it is still listed.
- Auralis checks that it can save undo information before writing its setting, and verifies removal before refreshing Chrome. Errors identify any step that needs attention, with **Install manually** available as a fallback.
- Confirmed uninstall takes precedence over cached browser connection status.
