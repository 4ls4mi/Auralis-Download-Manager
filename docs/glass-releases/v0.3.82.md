## Browser integration

- **Install automatically** checks for the existing extension, then saves and verifies its installation request. **Finish setup** reuses a saved request. Chrome 142 or later can reload the request while Chrome is running.
- **Reset extension setup** can remove Auralis’s own current-user setting even when another policy controls installation. Chrome reloads after verified removal. If the extension is still listed, remove it in the browser once its controlling policy has cleared.
- Windows can ask for same-account approval to undo setup after permissions change when Auralis created the entire Chrome policy value. Setup preserves unrelated browser policies.
- Browser host status skips absent policy keys. Auralis explains how to remove automatically installed extensions before setup and while it owns the setup. Confirmed uninstall supersedes earlier connection status.
