## Glass materials and backgrounds

- The main window and popups now use the same transparent Windows setup. When a window loses focus, it keeps its see-through tint so the Windows acrylic fallback can’t cover the desktop with a solid fill.
- All ten built-in materials have their own tint, lighting, panel layout, and button design. The layouts are distinct at the default window size too.
- **Settings → Appearance → Backgrounds** lets you choose desktop glass, a custom solid color, or an image or video. The main window and popups can each use a different background, including with either Aurora material.
- The **Glass translucency** slider still adjusts the glass strength. Color themes can tint the panels while each material keeps its own look.
