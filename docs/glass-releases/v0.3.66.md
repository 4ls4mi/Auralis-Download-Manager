## Security and privacy

- Paired remote clients receive less download information and cannot see or control private transfers.
- Browser handoff keeps request data scoped to its originating browser context, and local messaging now enforces input limits.
- Download, torrent, and extraction paths handle existing files and links more safely.
- The updater validates the release source and holds the verified installer in place through launch.
- Text from downloads stays plain text, and wallpaper and sound previews load local files only.
- Updated Qt to 6.11.3 and patched the Rust URL and MCP dependencies.

## Appearance

- Sharper layered action icons, material-specific bevels, softer highlights, and subtle idle motion.
