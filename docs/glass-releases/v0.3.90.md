## Appearance

- Edit the sidebar, center panel, menu and text colors for each material in Settings → Appearance. Choose a suggested swatch or make your own color. Auralis adjusts text contrast against each edited surface.
- Pick a preset button palette or set custom button colors. The Violet Rail Wide Sweep ribbon follows the selected tab's button color.
- Adjust progress bar thickness and connection block size independently. Progress shape choices now take effect with segmented layouts as well as continuous bars.
- Windows uses softer custom corners and a close, lower-right shadow on Auralis's main, settings and transfer windows. Native dialogs keep their system frames.

Existing materials and preferences keep their original colors until you customize them.
