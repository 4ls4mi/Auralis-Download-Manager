# Auralis Download Manager 0.3.25 — Windows x64

- Runs the downloader inside Auralis rather than launching a separate Mister-based downloader executable. The small browser native messaging helper remains separate, as required for browser integration.
- Keeps the existing download data and settings format, and waits for the downloader to save on exit and before an update.
- Windows tests covered a real download, browser-helper capture, shutdown and restart, and pausing and resuming a partial download with its file integrity verified. Existing installations and the in-app update handoff still require confirmation on an actual upgrade.
