## Language and display

- Switch between English, Arabic, Spanish, and Simplified Chinese in **Settings → General**. Arabic uses a right-to-left layout.
- Adjust font size and interface size with separate sliders. Preview and apply font changes in **Display & fonts**. Fully quit and reopen Auralis to apply the saved interface size.
- The font picker shows the 12 supported English and Arabic fonts and indicates which ones are installed on your PC.

## Browser setup

- Edge opens the Auralis listing in the Chrome Web Store. Auralis detects installed copies and clears earlier setup failures when it finds the extension.
- Auralis checks the extension, yt-dlp, FFmpeg, and gallery-dl at startup. The setup window opens only when a check confirms something is missing.

## Download progress

- The thinner pipes and progress bar move at a slower pace. Droplets ripple and splash in Classic, Water, and Jelly.
- A stalled connection keeps its measured fill against a red background. Pausing a download turns every connection block solid red.
