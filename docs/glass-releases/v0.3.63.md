## Download stability

- Transfer windows open after the download state and connection data have updated. The Windows resize handler also releases its hooks safely when a window closes.
- Corrected calculations in the progress shader used while transfers are active.
- Windows installer verification now starts, pauses, and resumes a real loopback download. It checks that the progress window renders on both start and resume and verifies the completed file.

## Windows icon

- The executable, running window, and installer shortcut use the coral-to-violet Auralis icon. Upgrades refresh the Windows icon cache for the executable while preserving existing pins.
