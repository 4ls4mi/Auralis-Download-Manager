# Auralis Download Manager 0.3.8 — Windows x64

- Addresses the reported in-app YouTube sign-in freeze by creating the WebView and reading its cookies off the Windows UI thread. A Windows smoke test checks responsiveness; a real Google account is still needed to verify sign-in.

- Shows subtitle languages as selectable visible lists in the thumbnail and player menus, rather than requiring a subtitle dropdown, and makes the quality menus wider. Lists are scrollable when there are many languages.
- Adds **Sign in to YouTube** to the thumbnail menu, player menu and extension popup. It opens YouTube in the same browser; sign in there, return to the video and fetch qualities with **Browser session** selected. This is separate from the experimental in-app sign-in window in the manual video helper.
- Shows the installed Auralis interface version, the upstream engine version and the extension version as separate values when available. Their independent version numbers are no longer compared as if they were one product.
- Prepares browser extension files in an Auralis-named folder under the user's local application data. Existing extension folders are left in place. Load the newly prepared folder in the browser, or remove the older unpacked copy first, then reload the browser extension.

The Windows build and automated tests check packaging and frontend behavior. Real browser sign-in, subtitle availability and YouTube extraction depend on the user's account, browser, site rules and network and need manual verification. The internal native-messaging host and existing data identifiers remain compatible with the upstream engine.
