# Auralis Download Manager 0.3.14 — Windows x64

- Simplifies Appearance settings, retaining Brushed Glass, Frosted Layers, Rose Pine, Window Glass and Oversimplified & Accentuated. Material, surface tint and indicator colors remain independently adjustable.
- Groups indicator fill and backdrop controls by progress, connections and graph; adds palette-matched glow to progress and connection fills.
- Updates native window clipping during resizing more frequently. Visual behavior on individual Windows setups can vary.
- Preserves downloaded byte-range attribution when a connection takes over a partially downloaded range. Connection assignments can still change as the engine redistributes work.
- Adds cookies.txt file selection to the extension's video and YouTube thumbnail menus, and an automatic private-session YouTube cookie export. Browser permission for private windows and interactive Google sign-in are required; Google may still restrict some videos.
- Fixes the installer upgrade test to check the configured application version rather than a hard-coded version.

The Edge Add-ons version requires a store-assigned extension ID to be added to Auralis before native messaging can be verified. Google sign-in and age-restricted playback require real-account validation.
