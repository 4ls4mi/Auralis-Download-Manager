## Transfer visuals

- Choose Satin Sweep, Faceted Crystal, Cross Lighting, Pinpoint Gloss, Fluted Glass, Iridescent Rim, Backlit Glass, or Edge-Lit Glass alongside the other lighting finishes. Progress, connections, and transfer graphs have independent color and lighting controls. The corresponding pipes use those choices.
- Color menus show gradient swatches, with eight additional palettes including Jade & Brass, Cherry Cola, Pearl Opal, and Copper Sky.
- Gushing Water runs from the inlet into the progress bar. Droplets scatter across the unfilled track and splash into the connection chambers. Wider hoses follow each row as the connection grid reflows.
- The download window adapts at narrow sizes, keeps its controls accessible, and lets users scroll to the connections and graph.

## Settings and Windows integration

- Settings has visible scrollbars and an Updates & About tab with the installed version, update controls, and recent release notes.
- Change font size live, preview English and Arabic fonts on hover, or set the interface scale for the next launch. Material themes have stronger action and navigation highlights.
- Optional startup setup checks for yt-dlp, FFmpeg, gallery-dl, and the browser extension. Guided extension setup detects Chrome or Edge as the Windows default and offers the store or supported per-user browser policy with approval.
- The Windows desktop interface uses Direct3D 12. The app, installer, and Control Panel entry display Alsami as the publisher.
