## Preferences across updates

Auralis preserves the saved interface scale, sidebar visibility, download sort order, and normal window sizes across updates and restarts. The main and transfer windows remember separate sizes for their compact and full views. Background installation waits while Settings is open.

## Fractured Acrylic

Fractured Acrylic now applies to the standard Auralis workspace. It keeps the existing download list, menus, toolbar, sidebar, and status area, with fitted edges and narrow seams between panels.
