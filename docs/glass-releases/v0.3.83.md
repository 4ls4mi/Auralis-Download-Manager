## First launch and settings

- One setup window guides you through language, video and gallery helpers, and browser integration. Pick English, Arabic, Spanish, or Simplified Chinese, or skip setup and return to Settings later.
- Browser integration has per-browser capture controls and its own Settings section. On Windows, Chrome offers the official extension for you to approve, and Edge opens the Chrome Web Store. Reset clears the installation offer or previous setup saved by Auralis.
- Fresh profiles start at 110% text size and 100% interface scale with a compact current download window. Windows bundles the selected Talina and Kidzhood Arabic fonts. Readable system numerals fill in missing or duplicate digits in the selected fonts.

## Desktop controls

- **Compact view** is labeled on both the main and current download windows.
- Right-click empty space in the download list to add a download, select all, sort, clear filters, or remove completed entries.
- **Hide to main window** moves the update out of its own window and shows ongoing progress in the download manager. You can reopen the updater from the progress card.
- The Windows installer omits six unused Qt styles.
