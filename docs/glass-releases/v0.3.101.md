## Transparent fills and layout-specific animations

- Add Liquid silk, Elastic gel, Photon streams, Crystal shimmer, Capillary current and Vortex glass.
- Give each of the eleven fill layouts three matching animation choices and a No motion option.
- Remember the animation selected for each layout, including in backups and exported themes.
- Migrate older global animation settings to a suitable layout-specific choice.
- Keep new artwork transparent around the fill and between its shapes, using the existing material track.
- Respect progress boundaries, frame shapes, palettes, lighting, compact sizing and reduced motion.
- Stop new animation clocks while hidden, paused, complete, or set to No motion.

Validation: 176 Qt rendering/integration checks and 20 Node regression tests passed before packaging.

The Windows installer remains unsigned. This release does not remove Windows publisher or SmartScreen warnings.
