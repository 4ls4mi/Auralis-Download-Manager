# Auralis Download Manager 0.3.9 — Windows x64

- Adds an experimental Frosted Layers material based on the supplied Water Bubble 3.5.1 pane renderer, preserving the existing download windows and engine behavior.
- Adds independently selected sculpted shapes and color palettes for total progress, connection indicators and graph backdrops, plus live settings previews. Shaped connections show an all-red track when paused and retain known progress on a red track after connection loss.
- Adds glass input fields, stronger text contrast and colored button highlights, and adjusts the small download-window layout to keep the buttons separate from the graph and connection grid.
- Adds automated checks for shaped progress and connection states. Browser previews use simulated downloads. The glass styling, Windows desktop composition, DPI scaling, real download behavior and performance have not yet been fully validated on Windows.

The downloadable installer is Auralis only; the bundled engine and browser host remain internal components used by the application.
