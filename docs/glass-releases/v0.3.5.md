# Auralis Download Manager 0.3.5 — Windows x64

## Downloads and windows

- Increases the default main, download-progress and settings window sizes by about 10%, subject to the available screen size.
- Keeps the hidden-download tray menu's items stable while their transfer information changes and restores the chosen download window through its existing window lifecycle.
- Makes selected rows more visible and adds an explicit **Also delete from disk** checkbox beside bulk deletion. The confirmation dialog still shows the final disk choice.

## Browser integration

- On the first launch, Auralis offers a browser setup guide when no recent connection has been observed. The guide explains browser-specific installation steps, opens the bundled extension folder, and registers the native helper.
- Browser Integration and the guide distinguish helper registration from a recently observed browser-to-helper connection. The status describes a recent handshake; it is not a permanent installation or live-health guarantee.
- The YouTube thumbnail menu groups available video, audio and subtitle choices in separate sections, shows subtitle languages, and uses a more compact glass-styled control.

## Appearance

- Adds solid cobalt, emerald, orange, coral, violet and lime indicators alongside additional gradients. Progress, connections and graph colors remain independently selectable.
- Colors the button surface and border as well as its text, with stronger hover and click states.
- Adds experimental surface options inspired by the Windhawk Rose Pine, Window Glass, Oversimplified & Accentuated, Tinted Glass, Frosty Glass and Raycast themes. These are early Auralis adaptations, not pixel-identical reproductions; Windows visual comparison and further design work remain necessary.

Frontend automated tests include the thumbnail sections and download selection. Windows tray restoration, browser setup, per-site login behavior and all new visual styles require real desktop verification. Firefox temporary add-ons still require reloading after the browser restarts unless the extension is signed.
