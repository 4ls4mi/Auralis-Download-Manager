## Fractured Acrylic

Open **Settings → Appearance → Materials and color → Fractured Acrylic** to use the redesigned overview. It brings the selected download, queue, active connections, appearance options, and transfer rate into individually beveled violet panels with mint accents. The overview uses live download data.

On supported Windows desktops, the wallpaper remains visible through the seams and behind the frosted panels. The overview uses a simpler arrangement at smaller window sizes. Use **Open queue** to access the full download list and **View → Fractured Acrylic overview** to return.
