# Auralis Download Manager 0.3.29 — Windows x64

- Give glass materials distinct surfaces, button shapes, layouts and action colors while keeping color themes and indicator choices independent.
- Add Matte Obsidian, Smoked Glass and Pearl Frost materials.
- Export, edit and import declarative custom material files from Appearance settings. Custom materials are included in preferences backups. See the [material format guide](https://github.com/4ls4mi/Auralis-Download-Manager/blob/feature/auralis-frosted-candidate/docs/auralis-material-format.md).
- When a recognized, time-limited SourceForge mirror link is refused, try requesting a fresh public redirect for the same file. Some browser challenges can still prevent a download.

The Windows build runs engine, interface and integrated-application tests before release. The SourceForge recovery has not yet been verified against the originally reported rejected link; import/export dialogs also need hands-on testing on an installed Windows app.
