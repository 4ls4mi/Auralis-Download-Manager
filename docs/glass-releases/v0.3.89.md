## Appearance

- New profiles start with MDM Classic. All ten Mister Download Manager themes are available alongside the Auralis materials. The MDM presets use their original palettes, progress styles, and byte-range connection indicators.
- New profiles round the top corners with a 12 px radius. Choose square, top, bottom, or all corners and adjust the radius in Settings → Appearance → Window backgrounds.
- A dismissible Appearance shortcut on the main window helps new users find themes, colors, and effects.
- Rounded windows clip the background and hide the rectangular Windows blur around the frame.

## Windows

- DirectX 11 is the default. If an optional DirectX 12 session stalls or closes unexpectedly, Auralis switches to DirectX 11 on the next launch.
- Browser integration lists detected browsers including Brave. Install opens the official extension listing in the selected compatible Chromium browser.

## Support

- Patreon is a small icon in the main window. A labeled link stays at the top of Settings, and About explains what donations support.
