## Qt desktop app

- The Windows interface now uses Qt Quick and Qt Quick 3D. It uses GPU-accelerated Direct3D 11 by default. You can select Direct3D 12 with the Qt graphics override `QSG_RHI_BACKEND=d3d12`.
- The main download list, transfer window, settings, and task dialogs use a redesigned layout and action controls. The transfer window draws live speed and connection data from the integrated Rust downloader.
- Water Bubble, Ice Edge, Smoked Crystal, Frosted Layers, Aero Gloss, and Prismatic Glass give the interface distinct contours, reflections, and progress tracks. Aurora Glass Dark is the default for new Qt profiles. Appearance settings let you choose materials, change their translucency, and set separate solid, image, or video backgrounds.
- The installer continues to use the same download history and engine profile. Existing flows for torrent recovery, saved-file checking, and portable download archives remain available in the Qt interface.

## Windows and browser integration

- The package includes the Auralis browser host and extension downloads for Chromium, Edge, and Firefox.
- The update notice opens the update details or starts a checksum-verified installer download. The Windows installer supports the previous Auralis updater's upgrade and relaunch arguments.
