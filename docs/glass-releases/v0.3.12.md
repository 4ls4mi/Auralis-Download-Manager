# Auralis Download Manager 0.3.12 — Windows x64

- Removes the newer sculpted indicator designs. Existing saved selections fall back to Rounded.
- Makes the approved ice ribbon available with Rounded, Square, Faceted and Water droplet progress shapes.
- Shows real update-download progress, including downloaded bytes, total size and percentage, in both the update notification and settings.
- After the installer is downloaded and verified, starts the Windows installer automatically; its installation window takes over and Auralis restarts after installation. Download and verification errors remain visible and do not start the installer.
- The browser extension is bundled with Auralis. Browsers require installation or approval; store publication is needed for a simpler standard install.
- The updater flow has automated UI coverage; the installer handoff and automatic restart need confirmation on Windows.
