## Appearance

- Choose Status track, Pill segments, Thin line, or Striped fill for download progress. Each layout uses your selected material, colors, lighting, and animation.
- Select Violet Rail Wide Sweep to move the curved sidebar with the selected tab in Main and Settings.
- Rounded sliders use the active material’s accent and a contrasting handle.
- The Main, Settings, Current download, Start download, and Completed windows have broader corners that curve smoothly into the edges in windowed mode.
