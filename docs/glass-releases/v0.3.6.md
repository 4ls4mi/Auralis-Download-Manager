# Auralis Download Manager 0.3.6 — Windows x64

## Browser extension

- Refreshes the extension popup and player control with layered glass surfaces, clearer status and readable colors.
- Adds a **Show on this site** switch to restore a hidden video control. After changing it, reload the page. A global setting or wildcard exclusion can still require changes in Auralis Browser Integration settings.
- Routes the popup and video control's Open/Options requests to the Auralis windows. If the connection fails, the popup now reports the problem instead of silently closing.

## YouTube video helper

- Adds an experimental in-app YouTube sign-in option for manual video lookups. Sign in in the separate YouTube window and keep it open while looking up the video; its YouTube and Google session cookies are passed directly to the downloader for that lookup.
- Google may reject embedded sign-in, and YouTube may still refuse a request or require verification even when signed in. The existing browser-extension and manually supplied cookie options remain available.

The popup restore and failed-action behavior are covered by frontend tests. Windows native compilation, the extension-to-app actions, the embedded sign-in session and age-restricted YouTube lookups still need real Windows and browser verification.
