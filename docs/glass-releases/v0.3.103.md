## Fractured Pearl

Choose **Settings → Appearance → Materials and color → Fractured Pearl** for a pearl and charcoal main window. The header, sidebar, download area, and footer have narrow, uneven seams that show the desktop. Two small joins connect the header and footer to adjacent panels. The recent downloads panel appears on wider windows.

## Background updates

Enable **Help → Install updates in the background** to download and verify updates automatically. Auralis waits for downloads to finish, runs the Windows installer silently, and restarts in the system tray. This option starts off, and **Check for updates** remains available for manual updates.

## Download connections

The main window shows the configured chunk count alongside the active connections for each download. A download configured for 32 chunks with four live connections shows all 32 slots.
