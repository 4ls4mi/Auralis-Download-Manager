# Auralis Download Manager 0.3.39 — Windows x64

- Check saved blocks and prepare repairs from a compatible HTTP source. A local hash detects later changes; it does not prove the original data was correct. Resume and repair depend on the server.
- Search Internet Archive on request, or compare a torrent file or magnet with saved download pieces. A selected torrent can continue in a separate folder while preserving the original partial download. Only compared pieces are verified; remaining content may differ and peers are required. Automatic fallback is not yet available.
- Export and import the current editable theme, including indicator settings; improve appearance and contrast controls.
- Simplify the extension quality panel with separate video, audio and subtitle tabs.
- Remove the glossy sweep and reflections from progress-bar fills while keeping their colors and liquid motion.
- Improve interrupted segmented-video handling and progressive assembly, and retain automatically supplied whole-file checksums where supported. Some media still requires final processing or muxing.

Preferences backup does not yet include downloaded files or download history. Full-file backup and automatic torrent fallback remain in development.
