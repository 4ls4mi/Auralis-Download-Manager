# Auralis Download Manager 0.3.31 — Windows x64

- Add Black Onyx, Smoke Black, Frost White and Pearl White color themes, including neutral tint rendering for Frosted Layers.
- Add Clear, Soft, Frosted and Tinted glass starting points, with independent controls for opacity, tint strength and supported blur.
- Improve text contrast on light neutral surfaces. Material and indicator selections remain independent.

Windows backdrop blur depends on the selected material and Windows support. Frosted Layers draws its own glass surface; its custom-wallpaper blur remains adjustable.
