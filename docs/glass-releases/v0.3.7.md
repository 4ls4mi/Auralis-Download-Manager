# Auralis Download Manager 0.3.7 — Windows x64

- Fixes the reported app freeze when opening the in-app YouTube sign-in window by creating its WebView on a worker thread. Reading its session cookies also runs off the Windows UI thread.
- Prevents repeated clicks while the sign-in window is opening and displays an error if it cannot be opened.
- Adds a Windows smoke test that opens the sign-in window, reopens it, and checks that Auralis stays responsive when requesting session cookies.
- Publishes the Auralis installer without a duplicate Mister-named installer.

The smoke test checks responsiveness, not a real Google login. Google may reject embedded sign-in or require additional verification, and signed-in age-restricted video lookups still need testing with the user's own account. Browser-extension and manual-cookie methods remain available.
