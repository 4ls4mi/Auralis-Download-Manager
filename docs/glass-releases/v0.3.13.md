# Auralis Download Manager 0.3.13 — Windows x64

- Lists available network adapters with an Automatic choice and disconnected status; shows the running app version in Settings.
- Adds a file picker for Netscape-format video cookies, folder and sound-file pickers, DNS presets, and explanations for technical text fields.
- Browser video-quality selections open Download File Info first, retaining the selected quality, subtitles and browser context. Starting the download brings its progress window forward temporarily.
- The extension checks the browser for YouTube sign-in cookies and uses the selected browser session for explicit video lookups; a Google sign-in page opens if no session is detected. Google may still require additional verification or restrict access.
- Narrows the left edge of Frosted Layers and extends text and icon shading across materials.
- Checking “Also delete from disk” for multiple selected downloads now performs that action without another confirmation dialog.
- Adds a Windows installer smoke test for upgrading from 0.3.12 and automatically reopening Auralis. Browser sign-in, foreground behavior and the full updater flow still need real-device validation.
