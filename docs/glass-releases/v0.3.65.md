## Download windows

- Start and progress windows move independently of the main window.
- The progress window stays responsive while you resize it during a download.
- The progress window closes automatically when its download finishes.
- The completion window shows the download address, saved location, exact size, and actions to open, move, or drag the saved file. You can also turn off future completion dialogs.

## Appearance and browser extension

- Adjust the opacity of materials that do not use Windows acrylic.
- Use the dedicated Chrome Web Store ZIP to submit the Chromium extension.
