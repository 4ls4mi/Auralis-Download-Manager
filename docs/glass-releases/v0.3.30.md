# Auralis Download Manager 0.3.30 — Windows x64

- Fall back to release metadata from Auralis’s notification service when GitHub’s API is rate-limited or unavailable. The installer remains hosted on GitHub and is checked for the expected size and SHA-256 digest before installation.

The fallback relies on the notification service receiving the signed GitHub release webhook. Older installed Auralis versions do not have this fallback and may need a manual update if GitHub rate-limits their check.
