## Appearance

- Ten named classic materials now use the original theme colors, toolbar and category icons, and period-specific window controls. The main window uses a compact table and category tree. Settings and the current transfer window use horizontal tabs.
- Set Header and Footer colors independently for each material. The color picker uses a draggable hue strip and saturation and brightness sliders.
- A small dismissible preview in the main window links to Appearance while a classic material is selected.

## Transfers

- Connection blocks stay horizontal when reduced in size, and the grid adjusts the number of columns to fit the available width.
