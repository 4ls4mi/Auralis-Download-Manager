## Downloads

- Paste a public Bowfile share link into **Add URL** to download the file in Auralis. The downloader waits for the site's countdown and keeps the verified file response for **Start Download**.
- The browser extension explains when a download has to stay in the browser. Auralis also shows a dismissible notice for eligible transfers the browser keeps. Download File Info gives clearer guidance when a direct link returns HTTP 460.
- The download link feeds one recessed pipe that branches into the progress bar and every connection row. The shared pipe clears the action buttons as the window resizes.

## Settings

- Settings pages and the category sidebar show full-height, draggable scrollbars when content overflows.
- Find **Interface size** in **Display & fonts**. The new scale takes effect after a full restart. English and Arabic font choices and text size have live previews and an **Apply font** button.
- Choose whether a copied download link fills **Add URL**, starts a download, or is ignored. **Network adapter** lists **System default** and the detected adapters and preserves a saved adapter when it is unavailable.

## Browser integration

- **Install extension** guides setup in the detected Chrome or Edge browser, with a plain-language confirmation and manual installation available if automatic setup fails.
- The Chromium and Firefox extension packages are version **0.1.20**.
