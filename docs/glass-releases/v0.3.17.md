# Auralis Download Manager 0.3.17 — Windows x64

- Keeps connection blocks in their own positions when other connections stop or return.
- Prevents the downloader from repeatedly splitting and exchanging work after a connection is permanently refused. When necessary, remaining bytes are reassigned once so the file can still finish; the affected connection's assigned total may change at that point.
- Keeps the video-quality panel visible outside clipped YouTube thumbnails and within the screen, including on small thumbnails.
- Limits the video overlay menu to the available screen height and keeps its contents scrollable.
- Includes updated Auralis browser extension packages.
