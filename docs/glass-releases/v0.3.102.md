## New appearance presets

- **Mint Transfer Deck** puts the selected file in a jade glass panel beside recent transfers. The bottom strip shows progress and provides quick access to transfer controls.
- **Dark Studio** adds a frosted silver sidebar, graphite panels, queue shortcuts, and live transfer and connection readouts.

Choose either preset under **Settings → Appearance → Materials and color**. Use **Overview** in the sidebar to return to the dashboard and **All downloads** to return to the list.

Both presets use the existing controls for fonts, scaling, colors, backgrounds, and progress, graph, and connection indicators.
