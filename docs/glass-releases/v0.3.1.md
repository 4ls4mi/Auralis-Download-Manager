# Auralis Download Manager 0.3.1 — Windows x64

## Changes since 0.3.0 preview

- A connection that encounters a network interruption or retry is highlighted red independently, while its actual progress remains visible in the selected gradient. A brief interruption is retained long enough to appear even between interface refreshes. Pausing still turns the occupied slots red.
- Added a fork-specific in-app release check, changelog, installer download and verification against the GitHub release's SHA-256 digest, followed by a choice to restart and install. The original MDM release check remains separate.

The 0.3.0 preview does not contain the in-app updater; install this version manually once. Each later update needs a newer versioned public release containing one Windows x64 setup executable, its GitHub-generated SHA-256 digest, and release notes.

The Windows x64 installer build and automated native checks passed in [Actions run 44151010931](https://github.com/4ls4mi/misterdownloadmanager/actions/runs/44151010931). The later [public updater end-to-end run 44159354623](https://github.com/4ls4mi/misterdownloadmanager/actions/runs/44159354623) also passed: it exercised the real public release from the installed app, including installer download, digest verification, installation and restart. Its proof artifacts include screenshots and test results and are retained through 2026-12-01.

The 0.3.0 preview does not contain the fork updater, so install 0.3.1 manually once. Subsequent updates use the fork's own versioned public releases. Manual checks on ordinary user hardware—especially DPI, transparency and drag-to-Explorer behavior—remain separate from the automated updater test.
