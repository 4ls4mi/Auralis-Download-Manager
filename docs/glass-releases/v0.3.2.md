# Auralis Download Manager 0.3.2 — Windows x64

## New identity and tray behavior

- Rebranded the Windows desktop application as Auralis Download Manager, with an original crystalline A/download icon.
- Expanded the shared Windows notification-area menu to include the familiar MDM actions: Add new download, batch download, batch-from-clipboard entry, downloads in progress, Speed Limiter, Scheduler, start/stop main queue, Options and Exit.
- Added per-download entries under Downloads in progress. Hiding a floating progress window adds it to the shared tray menu; selecting that specific entry restores only its matching window.

## Compatibility

- The Tauri application identifier remains unchanged to preserve the existing installation's application-data location during upgrade.
- The fork updater now expects the Auralis installer asset name. The release also carries a legacy `Mister.Hybrid.Glass_0.3.2_x64-setup.exe` alias so existing 0.3.1 installations can take their first branded update without losing the in-app updater path.

## Validation

- Windows x64 build and automated tests passed in [GitHub Actions run #24](https://github.com/4ls4mi/misterdownloadmanager/actions/runs/44201539195) and [run #25](https://github.com/4ls4mi/misterdownloadmanager/actions/runs/44201545843).
- Manual Windows acceptance checks have been completed: icon inspection at multiple DPI scales, tray-command verification, independent restoration of hidden progress windows, and an in-place upgrade from 0.3.1 preserving downloads, settings and the updater.

This release is the Auralis Download Manager 0.3.2 Windows x64 release.
