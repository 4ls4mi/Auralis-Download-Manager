## Settings and appearance

- Restart Auralis from Settings after changing the interface size.
- Find and import your licensed copies of the requested English and Arabic fonts.

## Browser integration and downloads

- Open the Chrome Web Store listing directly in Edge and detect an existing extension installation.
- Suggest a download description from available file metadata, page or video title, or the file name.

## Maintenance

- Store managed media helpers in the Auralis folder and migrate compatible existing installations.
- Choose whether to remove Auralis app data and shared download history during uninstallation.
