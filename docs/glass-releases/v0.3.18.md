# Auralis Download Manager 0.3.18 — Windows x64

- Adds checkboxes for individual downloads and a select-all control for the current list, plus a Start selected action for starting multiple downloads.
- Aligns the frosted glass window's native boundary with its rendered outline, allowing clicks outside the glass to reach windows behind it.
- Reduces work during live window resizing by reusing the glass outline and deferring layout recalculation until resizing pauses.
