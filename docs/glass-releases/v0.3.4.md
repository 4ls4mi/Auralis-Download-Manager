# Auralis Download Manager 0.3.4 — Windows x64

## Downloads and tray

- The progress-window tray icon is shown only while one or more progress windows are hidden. Its menu lists hidden downloads with available status, progress, speed, time remaining, active connections and resumability.
- Download lists default to newest first and can also be sorted by age, name, size or status. Use Ctrl-click or Shift-click to select downloads and open, remove or extract them together. The delete confirmation includes the option to delete files from disk. The existing extraction engine recognizes multipart archives.
- The main and progress windows have smaller new-install defaults, and the Auralis executable has an updated name.

## Appearance

- New installations use Deep Indigo, brushed glass, Tahoma 18, full opacity, a 255 tint hue and 50% tint strength. Existing preferences are preserved.
- Select progress-bar, connection-block and graph colors separately, choose their shapes, and preview them side by side.

## Browser extension and video

- The installer includes the Auralis browser extension. Browser Integration prepares a browser-specific copy, repairs the native connection and explains the manual browser installation steps.
- Thumbnail menus show separate video, audio and subtitle sections, with visible subtitle languages. Browser-session video lookups include the originating YouTube and Google cookies when the user requests browser cookies. Manual cookies remain available.
- Edge/Chromium require developer mode for an unpacked extension. Firefox's temporary add-on installation lasts until Firefox closes; permanent installation requires signing. YouTube can still require authentication or refuse a lookup despite valid browser cookies.

## Updates

- Checks for Auralis releases in the background and offers a movable changelog window, download and restart controls, and reminders after a duration or at a chosen date and time.
- Keeps an already downloaded installer available across background rechecks and reports a missing release feed as an error.

The preceding Windows test build passed its automated checks. Real Windows tray behavior, the upgraded installer's update path, and signed-in Edge/YouTube lookups still need manual verification. The requested Windhawk-inspired material designs and remaining button styling are not included in this release and remain in progress.
