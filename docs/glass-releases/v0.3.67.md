## Browser integration

- Open the official Chrome Web Store listing from Auralis, verify the extension connection, and access Chrome’s extension manager for manual update checks.

## Indicators and controls

- Choose Classic, Normal, Gushing water, or Jelly independently for progress bars, connections, and speed graphs. Each style uses the selected indicator colors.
- The download window’s side pipes carry animated flow from the inlet to the progress bar and connection chambers.
- Action buttons have more vivid hover and selection colors. Enabled icons animate gently while visible and respect the reduced-motion setting.
