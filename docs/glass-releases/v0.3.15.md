# Auralis Download Manager 0.3.15 — Windows x64

- Bundles a checksum-verified Deno JavaScript runtime for yt-dlp's YouTube challenge solver. This can resolve missing-format errors when the runtime was absent; YouTube may still restrict some videos.
- Refreshes the browser extension's video capability on demand and reports temporary native-host errors without disabling future lookups.
- Restores Frosted Layers opacity control, respects the completed-dialog preference, makes download-list columns resizable and enlarges connection blocks.
- Sets first-install appearance defaults to 90% interface size, 14 px Trebuchet, blue/purple indicators and rounded recessed ice backdrops. Existing preferences are retained.

A real YouTube lookup and Windows UI verification remain necessary. The Edge Add-ons version requires its store-assigned extension ID before native messaging can be verified.
