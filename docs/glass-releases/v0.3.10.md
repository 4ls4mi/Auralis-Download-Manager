# Auralis Download Manager 0.3.10 — Windows x64

- Checks the Auralis release feed at startup and after release signals or reconnecting to the notification service, independently of the download engine. When a new release is found, the app shows an in-app notice and a movable window with the changelog, download and reminder choices. A Windows notification is also requested when permitted.
- Brings the update window forward briefly without leaving it permanently on top. The update remains optional and the installer is downloaded and verified before the user chooses to restart and install.
- Clips wallpaper and solid backdrops to the Frosted Layers glass outline and makes the visible pane edge the resize target. Child windows explicitly request a transparent native background.
- Gives the main download list larger progress and connection indicators, adds independent finishes and color palettes for progress and connection backdrops across indicator shapes, and removes graph backdrop styles.
- Notifications require the app and the release signal service to be online. A reconnect triggers a fresh GitHub check; there is no periodic five-minute polling.
- Automated browser tests cover update reminders, transparent browser corners and resize hit testing. Actual Windows notifications, desktop compositing, native edge dragging, update installation and multiple DPI settings still need real-device verification.
