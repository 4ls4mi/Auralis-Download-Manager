# Auralis Download Manager 0.3.24 — Windows x64

- Adds **Start Auralis with Windows** in General settings. Choose whether Auralis opens its main window or starts minimized in the system tray when you sign in.
- Keeps ordinary manual launches visible and restores an already running instance from the Auralis tray icon.
- Uses a per-user Windows startup entry for Auralis. The bundled downloader continues to operate as before.

The settings interface and error handling have been tested. Actual startup behavior and tray restoration need a Windows sign-in test.
