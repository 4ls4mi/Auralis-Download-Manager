# Auralis Download Manager 0.3.21 — Windows x64

- Adds Sculpted Liquid Glass, Pressurized Crystal and Soft Aero Water as independently selectable materials for progress fills, connection fills and transfer graphs under Appearance → Indicators. Existing styles and chosen track shapes, backdrops and indicator palettes remain available.
- Adds animated liquid fronts and droplets, with animation speed adjusted for file size, plus connection-block waves and splashes. In the progress window, paused blocks remain red; interrupted blocks keep their measured fill over a red backdrop.
- Adds a liquid graph based on actual speed samples, with a bottom-aligned zero baseline and animated surface reflections. The shape follows the reported history rather than inventing speed values.
- Uses one shared WebGL context for liquid progress shading, with a 2D fallback and reduced-motion support. These are physics-inspired effects; they are not a full fluid simulation or a pixel-perfect reproduction of the design concept. Windows appearance and GPU performance still need user testing.
- Fixes a pending thumbnail scan that could recreate an old YouTube control after extension reinjection. Reload open YouTube tabs after updating the extension.
