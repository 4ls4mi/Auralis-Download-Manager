# Auralis Download Manager 0.3.3 — Windows x64

- Adds development builds of the Auralis browser extension for Chromium-based browsers and Firefox, including thumbnail controls, video and audio choices, subtitle languages, and per-video cookie options.
- Adds a browser selector and per-video pasted cookies to the manual video helper. Browser access to encrypted cookies and available qualities depend on the browser and the site.
- Adds a separate tray list for download progress windows, compacts the connection blocks and graph, and introduces an experimental water-droplet progress indicator.
- Corrects updater handling for the renamed GitHub repository and installer, and prevents a repeated workflow run from overwriting an existing public release.

The browser extension ZIPs are development packages. Firefox requires signing for permanent installation, and Safari requires separate packaging. Real-site browser testing, Windows tray and visual checks, and comparison of the water-droplet indicator to the concept remain outstanding.

Existing 0.3.2 installations may need a one-time manual installation because that version's updater expects the old release URL and installer name.
