## Initial setup

- Initial setup always includes Language, Browser integration, then Video and gallery helpers.
- Browser detection and previous extension connections update the browser page's status without hiding the page.
- Installed helpers still appear on their setup page.
- Skip and Close remain available. This corrected setup is offered once to profiles that missed the browser page.

## Uninstall

- Uninstall requires Auralis and its browser helper to close before removing files.
- File removal errors stop uninstall and retain its registration and settings for a retry.
- The fresh-reinstall option clears standard app settings, caches, helpers, and download history while keeping downloaded files.
