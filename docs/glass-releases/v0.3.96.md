## Window resizing

- Apply the existing 16 ms resize coalescing path to Settings and all shared detached dialogs.
- Disable the competing Windows resize hook in Settings.
- Enable resize coalescing by default for shared resize handles, covering Add Download, confirmations, completion, startup setup, and update dialogs when they use manual resizing.
