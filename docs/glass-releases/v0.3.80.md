## Browser integration

- Auralis checks the browser for the extension before attempting automatic setup. If an install request was already saved, **Finish setup** reuses it and clears any stale refusal once Auralis sees the saved request or installed extension.
- Chrome 142 or later can refresh a saved install request immediately while Chrome is running. **Install manually** remains available when the browser needs user confirmation.
- **Reset extension setup** clears the automatic setting Auralis created and asks supported Chrome versions to reload. If the extension remains installed, it can be removed from the browser’s Extensions page once the change applies.
- Confirmed removal takes precedence over an earlier browser connection. Windows setup errors explain why Chrome approval was unavailable.
