## Setup window

- The setup wizard now has its own first-run marker, independent of appearance preferences and download history. This also offers setup once to existing installations that missed it.
- Settings includes **Set up Auralis** to reopen language, browser integration, and video and gallery helpers at any time.
- Reopened setup includes all three pages, including components already installed. Skip and Close remain available.
- Setup opens when the main window is visible, including when Windows has not given it keyboard focus.
- A small language selector in the main window footer saves and applies your choice immediately.
