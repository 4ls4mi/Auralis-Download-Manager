## Chrome setup

- **Install automatically** starts browser setup in one click. Windows can request permission when eligible Chrome setup needs it, and **Install manually** opens the Chrome Web Store if needed.

## Downloads

- Right-click an eligible download and choose **Refresh download address** to provide a replacement URL and keep the existing partial download.
- Start Download shows total and available space on the selected destination drive.
- Both the main window and the current download window have a compact view with smaller animated progress bars, connection indicators, and speed graphs.
