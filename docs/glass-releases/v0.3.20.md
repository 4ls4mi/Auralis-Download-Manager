# Auralis Download Manager 0.3.20 — Windows x64

- Show file sizes for video and audio qualities in YouTube thumbnail menus, including estimates. Show when a size is unavailable; subtitle sources do not normally provide sizes.
- Show a red background for an interrupted connection in both the main download list and the current download window, independent of backdrop colors and finishes, while retaining its progress fill.
- Use the main window’s Windows transparency settings for update and other secondary windows, reducing unwanted bright backing.
- Improve the self-hosted build cache so changes confined to the interface or extension can reuse the backend executable.

Reload open YouTube tabs after updating the browser extension.
