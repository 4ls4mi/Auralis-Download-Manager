# Auralis Download Manager 0.3.22 — Windows x64

- Rearranges the download window with the connection blocks on the left, the speed graph on the right, and the progress bar above them.
- Adds translucent tubes from the download address to the progress bar and from the progress bar to the connection grid. Colored flow follows the selected indicator colors and appears only on paths serving receiving connections; interrupted blocks retain their existing progress and red backdrop.
- Keeps the liquid indicator materials independently selectable. The tubes are a decorative representation of reported connection state, not a physical fluid simulation.

The layout has been checked in browser rendering tests at several window sizes and scales. Its appearance and performance in the installed Windows app still need confirmation.
