## Interface refinements

- Surface material choices now clearly mark the selected material.
- The connection previews are larger. Download rows show file size once, combine status with speed, and give the progress, connections and graph room to display.
- Settings now provide a searchable list of preferences; Advanced no longer opens an empty Common settings page.
- The browser video panel truncates long titles and uses compact internal scrolling. Its existing video, audio and subtitles tabs remain available.
- Falling connection droplets follow the selected connection palette for every fill style while receiving.

The browser extension packages in this release contain version 0.1.11. Store updates require a separate submission to the relevant browser store.
