## Settings and indicator customization

- Add the second collection of creative progress layouts and graph materials.
- Connect creative progress rendering to shape, lighting, colors, and named motion effects.
- Respect area, line, and bar graph shapes while retaining measured sample values.
- Add category creation/editing, folder browsing, and per-category folder memory to Save to.
- Add a separate File types page with capture rules, exclusions, and restore-default controls.
- Offer bounded connection choices, extended limits up to 128, and valid port ranges.
- Add installer choices for starting with Windows and starting minimized.
- Refresh the first-run guide with bundled animated illustrations.
- Expose the existing locale catalogs in the Qt interface and installer. Some translations
  remain incomplete and fall back to English; 87 locale choices do not mean 87 fully
  translated languages.
- Add startup-channel diagnostics, native packaging preflight checks, and rendering tests.

This release does not introduce trusted Authenticode signing or promise removal of
Windows SmartScreen warnings. Free signing requires separate provider approval.
