# Auralis Download Manager 0.3.26 — Windows x64

- Save and restore appearance, download and Windows startup preferences; new installations offer to restore an existing backup. Passwords, account credentials and browser cookies are not included. Paths to files and folders may need updating on a different PC.
- Choose a bottom-right update notice or a prominent update window under Settings → Advanced → Updates.
- Fix the maximize/restore control and simplify the main queue action in the tray.
- When one download window is hidden, the progress tray icon shows its information and restores it on click. With multiple windows, click to open a list and hover for details.
- Add falling liquid droplets to actively receiving liquid connection blocks; animation honors the existing indicator colors and reduced-motion setting.
- Close the browser setup or yt-dlp helper window after the selected browser connects or yt-dlp finishes installing successfully.
- Refresh the project README with screenshots of the current interface and an animated liquid-indicator preview.
