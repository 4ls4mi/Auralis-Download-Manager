# Guide d’Auralis Download Manager — brouillon

Brouillon pour la prochaine version : vérifiez les fonctions dans ses notes avant publication.

- **Installation :** installez la version Windows x64 depuis les [versions](https://github.com/4ls4mi/Auralis-Download-Manager/releases/latest). Dans **Settings → Browser Integration**, choisissez **Set up everything**, puis installez l’extension dans le navigateur.
- **Téléchargements :** cliquez sur **Add URL**, saisissez une adresse HTTP, HTTPS ou FTP et choisissez la destination. L’extension peut aussi envoyer les liens compatibles. Ouvrez un téléchargement pour voir sa progression, ses connexions et sa vitesse.
- **Reprise :** utilisez **Pause** et **Resume**. Si le lien a expiré, arrêtez le téléchargement puis utilisez **Refresh download address** avec un nouveau lien vers le même fichier. La reprise dépend du serveur. Les segments ordinaires sont écrits pendant le téléchargement dans un seul fichier temporaire ; l’écriture finale et la vérification peuvent prendre du temps.
- **Files et vitesse :** sélectionnez les fichiers puis **Add to queue**. Utilisez **Scheduler** pour les horaires et **Speed Limiter** pour limiter un téléchargement.
- **Vidéo et audio :** après configuration de l’extension et de yt-dlp, ouvrez une page compatible et choisissez la qualité et les sous-titres. Les tailles ne sont affichées que si elles sont disponibles ; certains formats nécessitent FFmpeg pour réunir la vidéo et l’audio.
- **Torrents :** utilisez **Add Torrent** pour ouvrir un fichier `.torrent` ou coller un lien magnet, puis vérifiez les fichiers et la destination. La disponibilité dépend des pairs.
- **Apparence :** dans **Settings → Appearance**, choisissez couleurs et matériau ; dans **Indicators**, réglez séparément la barre, les connexions et le graphique. Exportez un matériau JSON avec **Export current theme…**, modifiez-le, puis utilisez **Import theme…**. Voir le [format](../auralis-material-format.md).
- Avant de sauvegarder ou de restaurer les téléchargements, arrêtez les transferts, les vérifications et les files d’attente. Dans **Settings → General → Download backup**, choisissez **Back up downloads…** pour sauvegarder les préférences, l’historique, les files d’attente, les fichiers pris en charge et la progression enregistrée. Dans la nouvelle installation, choisissez **Restore downloads…**, puis l’archive et le dossier de destination. **Preferences backup** sauvegarde les réglages seuls au format JSON. Les mots de passe et les cookies sont exclus.
- **Démarrage et mises à jour :** réglez le démarrage Windows dans **Settings → General** et les notifications dans **Advanced → Updates**.

Les empreintes locales détectent les modifications ultérieures, mais ne prouvent pas à elles seules l’authenticité des données. Dans la fenêtre de téléchargement, **Check saved data** vérifie les blocs dont les empreintes sont enregistrées ; **Check source and repair** prépare leur réparation si le serveur HTTP est compatible.

Dans la prochaine version pour Windows, activez la récupération automatique sous **Settings → Torrents**. Lorsqu’un téléchargement direct éligible a épuisé ses tentatives, Auralis recherche dans Internet Archive à partir des mots du nom de fichier. Vous pouvez vérifier la correspondance vous-même ou autoriser la reprise automatique si un seul résultat correspond, si au moins deux pièces enregistrées sont vérifiées et si toutes les vérifications ont abouti. Les téléchargements privés et ceux avec une somme de contrôle attendue pour le fichier entier sont exclus.

Dans la fenêtre de téléchargement, **Find a torrent for recovery** permet aussi de vérifier un fichier torrent local, un lien magnet ou une URL publique HTTP(S) de torrent. Auralis copie les pièces vérifiées dans un nouveau dossier, conserve le fichier partiel d’origine et récupère les pièces manquantes auprès des pairs BitTorrent. La fenêtre affiche les détails du transfert, et la liste indique **Direct → Torrent** pour les téléchargements récupérés.
