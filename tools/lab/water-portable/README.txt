Mister Hybrid Glass - experimental Water Bubble window

Windows 11 x64 only. This is a standalone development test, not the finished theme or an installer. It has its own temporary download-manager and WebView data. It does not capture or transmit your desktop.

1. Close the normal Mister Hybrid Glass application first, including its tray icon. The app uses a single-instance mechanism.
2. Extract every file in the ZIP to one folder.
3. Run Start-Water-Test.cmd from that folder.
4. Start a download, then inspect the download progress window in front of a colorful desktop or another window. The current prototype does not yet implement physical refraction and may fall back to an opaque surface.
5. Close the experimental app from its tray before reopening the normal app.

The normal installed app and its download list are not intentionally changed by this standalone test. Do not use it for important downloads; it is a development candidate.
